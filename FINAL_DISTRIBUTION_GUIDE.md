## 🎮 How to Use

After installation, TempSticky starts automatically!

**Settings:** Right-click tray icon  
**Quit:** Right-click tray → "Quit TempSticky"

## 🔧 Troubleshooting

**Can't see tray icon?**
- Click the `^` arrow in system tray
- Drag TempSticky icon to main area

**Temperature shows N/A?**
- Update chipset drivers
- Some laptops don't expose sensors

**Windows SmartScreen warning?**
- Click "More info" → "Run anyway"
- Normal for new apps

## 🗑️ Uninstall

1. Right-click tray icon → Quit
2. Settings → Apps → TempSticky → Uninstall
3. Or run the uninstaller from Start Menu
